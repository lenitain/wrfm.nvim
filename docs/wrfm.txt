==============================================================================
INTRODUCTION                                                    *wrfm*

wrfm.nvim renders `.wrfm` 3D wireframe models inside Neovim using Unicode
braille characters in a floating window. It needs nothing but Neovim >= |0.11|
and works over ssh/tmux where image protocols do not.

The `.wrfm` format is the wireforge project's text format.  The project
and format docs live at:
https://github.com/Vaishnav-Sabari-Girish/wireforge

Features~
- Zero dependencies: only Neovim >= 0.11 required
- Braille rendering: Unicode braille characters (U+2800-U+28FF)
- Multiple viewer modes: floating window and inline preview
- Live hot-reload: auto-update when .wrfm files change
- Auto-spin animation: smooth rotation with libuv timers
- Works everywhere: ssh, tmux, tty, any terminal

Opening a `.wrfm` file sets `filetype=wrfm` (shipped ftdetect), which arms
the auto-attach integration below.

Run `:helptags ALL` after installation to enable the tags below.

SETUP                                                           *wrfm.setup*

>lua
    require("wrfm").setup({
      -- Canvas size (braille character cells)
      -- nil = auto-calculate from window dimensions
      default_width = nil,
      default_height = nil,

      -- Size caps
      max_width = nil,            -- hard cap in columns (nil = unlimited)
      max_height = nil,           -- hard cap in rows (nil = unlimited)
      max_width_window_percentage = 80,   -- % cap relative to host window
      max_height_window_percentage = 60,  -- % cap relative to host window

      -- Camera
      default_pitch = 30,         -- initial pitch (degrees)
      default_distance = nil,     -- camera distance; nil = auto-fit
      default_fov = 60,           -- vertical field of view (degrees)

      -- Overlap compositing (inline)
      default_overflow = "clip",  -- "clip" or "visible"
      default_z_order = "model",  -- "model" or "text"

      -- Animation
      default_auto_spin = true,   -- spin after render()
      default_spin_speed = 0.02,  -- radians per frame
      fps = 30,                   -- animation frame rate

      -- Hot reload
      default_watch = true,       -- hot-reload .wrfm files by default

      -- Appearance
      highlight = "Yellow",       -- wireframe color: hex "#RRGGBB" or a
                                  -- theme highlight group to link

      -- Inline preview
      integrations = {
        wrfm = {
          enabled = true,                     -- auto-attach for *.wrfm
          clear_in_insert_mode = false,       -- hide during insert mode
          only_render_at_cursor = false,      -- show only at cursor
          cursor_mode = "popup",              -- "popup" or "inline"
          filetypes = { "wrfm" },
        },
      },
    })
<

`setup()` is optional. Unknown keys raise an error.

COLOR                                                                *wrfm.color*

The wireframe color is set with the `highlight` option, one of two forms:

- A hex value (`"#RRGGBB"`) paints the art in exactly that color and always
  wins, even across colorscheme switches.
- Any other string names a highlight group to link `WrfmPreview` to, so the
  color follows the active colorscheme (and updates on `:colorscheme`).
  The default is `"Yellow"`. Like an unset link, the link is applied with
  `default = true`: a colorscheme that defines `WrfmPreview` itself still
  takes precedence.

Malformed values (e.g. `"#12"`) raise on |wrfm.setup()| like unknown keys.
All live views recolor instantly, because highlights resolve by name at draw
time; no re-render is needed. Change the color at runtime with
`require("wrfm").set_highlight("#00ff88")`.

The size caps clamp derived AND explicit sizes: a canvas never exceeds
`max_width_window_percentage%` of its host window (`max_height_window_
percentage%` for rows) nor the absolute `max_width`/`max_height`, whichever
is smaller. Per-model overrides and an `ignore_max_size` opt-out exist (see
|wrfm.from_file()|).

QUICK START                                                 *wrfm.quickstart*

1. Install Neovim >= 0.11
2. Install the plugin (see |wrfm.installation|)
3. Open a .wrfm file or run |:Wrfm|
4. Check |wrfm.howto| for common tasks

Requirements~
- Neovim >= 0.11 (uses extmark virtual lines and modern APIs)
- Terminal with Unicode braille support (virtually all modern terminals)

Because output is ordinary text, it works everywhere Neovim does — including
tmux, ssh and tty. No graphics protocols, no ImageMagick, no external
dependencies.

API                                                        *wrfm.from_file*

                                                          *wrfm.from_file()*
    wrfm.from_file({path} [, {options}])

Load and register a model. Returns a |WrfmModel|. An id is assigned from
`options.id` or sequentially as "model-N". Passing an `options.id` that is
already live returns the existing model unchanged - other options in that
call are ignored (so repeating a call never stacks viewers). Raises when
{path} cannot be read or parsed. Options:

    window      anchor the float to this window instead of the editor grid
    buffer      draw into this buffer instead of opening a float
    width/height  canvas size in braille cells (both derived by default)
    x/y         offset from the centered float placement in editor cells;
                applying them overrides a manual move() position
    max_width_window_percentage/max_height_window_percentage
                per-model percentage caps overriding the setup defaults
    ignore_max_size  lift percentage and absolute size caps for this model
                (terminal bounds still apply)
    distance    pin the camera distance (nil auto-fits)
    fov         vertical field of view in degrees (default: default_fov);
                independent of `distance` - fov sets how much of the world
                the viewport shows, distance sets how far the model sits
    pitch/yaw   initial angles in degrees
    auto_spin   start spinning right after render()
    spin_speed  radians per frame
    pause_spin_when_unfocused
                pause auto-spin while the host window is not focused
                (default: the pause_spin_when_unfocused setup option)
    watch       hot-reload the file (default: default_watch)
    border      float border and title (default true); false renders a
                seamless frameless overlay - only the braille art shows,
                background merged into the host window (image.nvim look)
    overflow    inline overflow behavior (default: default_overflow):
                "clip" truncates the artwork at the canvas edge; "visible"
                bleeds it into the surrounding text, skipping cells that
                have nowhere to land. Floats are always clipped by their
                own window.
    z_order     how an inline preview composites where it overlaps other
                cells (default: default_z_order): "model" paints over the
                cell, "text" yields it to the buffer's content.
    namespace   registry tag for get_models() filtering
    id          stable registry identity

                                                        *wrfm.model-methods*
A WrfmModel exposes:

    model:render([{geometry}])
                          draw now; opens/creates the view. With {geometry}
                          (`{ width =, height =, x =, y = }`), the given
                          axes become the new canvas size / placement offset
                          first and a live float is resized or shifted in
                          place; the change persists across later renders.
                          Returns false if rendering is globally disabled or
                          queued until |VimEnter| (silent no-op). Before the
                          UI exists the first draw is deferred to VimEnter,
                          when terminal dimensions are known.
    model:move({x}, {y})  reposition the floating window to editor-relative
                          coordinates (0-based); size/border/title are kept.
                          No-op for inline and bound-buffer models.
    model:hide()          hide the view without unregistering: timers stop,
                          floats close, bound buffers restore; camera, spin
                          and watch state is preserved for show().
    model:show()          restore a hidden model; no-op when already
                          visible. Returns false while rendering is globally
                          disabled.
    model:clear()         destroy the view, stop timers/watchers, unregister.
    model:set_spin(bool)  toggle animation (nil inverts current state).
                          Spinning is a relative rotation around the model's
                          own Y axis (wireforge's Space auto-spin; see
                          https://github.com/Vaishnav-Sabari-Girish/wireforge),
                          not a world-frame turntable.
    model:set_pitch(deg)  tilt to {deg} degrees via a world-frame delta
                          (wireforge arrow-key semantics, see
                          https://github.com/Vaishnav-Sabari-Girish/wireforge)
                          and repaint.
    model:set_distance(d) pin camera distance (nil = auto-fit) and repaint.
    model:set_fov(deg)    set the vertical field of view in degrees and
                          repaint. FOV and distance are independent knobs:
                          widening the FOV shows more of the world (bigger
                          art) without moving the camera, which is what
                          `distance` does.

    model:footprint()     the model's true display range for the current
                          view, in absolute cells: `occupied, min_col,
                          max_col, min_row, max_row`. Whatever lands
                          outside the canvas is what `overflow = "clip"`
                          throws away.
    model:overflows()     boolean: whether the footprint reaches past the
                          canvas. This is the condition `overflow =
                          "visible"` keys off to decide whether to bleed.

    model:footprint()/`overflows()` are the diagnostic pair behind
    truncation: the footprint is fixed by FOV + viewport + distance, and
    the canvas is only a crop box. To stop an inline preview clipping,
    widen the canvas, raise `distance`, or widen the FOV.

The live orientation is kept as a rotation matrix, so spin accumulates
relative to the current pose; `pitch`/`yaw` only mirror the display angles.

Viewer floats are decorations: they open non-focusable, so your keys keep
going to the window you were in. Close viewers with |:WrfmClear|.

                                                               *wrfm.api*
Registry and global switch:

    wrfm.get_models([{opts}])  live models; filter with {window=winid},
                               {buffer=bufnr} or {namespace=tag}
                               (conjunctive).
    wrfm.clear([{id}])        destroy one viewer by id (every match), or all
                               without arg.
    wrfm.hide([{id}])         hide views without unregistering (one by id or
                               all); show()/enable() bring them back with
                               their view state intact.
    wrfm.show([{id}])         restore hidden models (one by id, or all).
    wrfm.enable()             re-render every registered model.
    wrfm.disable()            hide views; models stay registered; render()
                               becomes a silent no-op returning false.
    wrfm.is_enabled()         current switch state.
    wrfm.current              most recently created model (may be nil).

                                                            *wrfm.attach()*
    wrfm.attach({bufnr} [, {opts}])

Attach an inline preview to {bufnr}.  The buffer's filename is used to locate
the `.wrfm` source unless `opts.path` is given.  Attaching to a buffer that
already carries an inline preview re-renders it instead of stacking a second
extmark/timer. Returns a |WrfmModel|.

                                                           *wrfm.detach()*
    wrfm.detach({bufnr})

Remove all inline previews from {bufnr}.

COMMANDS                                                    *wrfm.commands*

                                                                 *:Wrfm*
:Wrfm [file]    View {file} (default: current buffer's file) in a floating
                window. Repeating the call re-renders the existing viewer
                for that file instead of stacking a second one.

                                                            *:WrfmClear*
:WrfmClear [id] With an id, close exactly that viewer; without, close all.

                                                             *:WrfmList*
:WrfmList       List live viewers: id, mode, spin state, source path.

                                                               *:WrfmHere*
:WrfmHere       Attach an inline preview to the current buffer.

                                                            *:WrfmDetach*
:WrfmDetach     Remove the inline preview from the current buffer.

                                                           *:WrfmReport*
:WrfmReport     Open a diagnostic report in a floating window: Neovim and
                platform info, active configuration, a live snapshot of every
                registered model (id, mode, namespace, canvas size, camera,
                spin/watch state, buffer/window ids) and resource counts.

LIFECYCLE                                                    *wrfm.lifecycle*

Spin timers pause automatically when Neovim loses focus (|FocusLost|) or is
suspended (|VimSuspend|), and resume on |FocusGained| / |VimResume|. Views
stay visible - braille frames cost nothing to keep on screen. Manually
stopped spins (|wrfm.model-methods| set_spin(false)) are never resurrected.

By default (pause_spin_when_unfocused = true) a model whose host window is
not the focused window stops repainting: a dashboard logo hidden behind a
fullscreen terminal float, or a preview in a split you stopped looking at,
no longer burns a frame every tick. The timer keeps running, so the spin
resumes the moment the host window regains focus. Disable the option to keep
background models spinning unconditionally.
Bursts of relayout/reload events within one event-loop turn coalesce into a
single repaint.

Stale contexts are swept automatically: after |TabEnter|, |BufEnter| or
|WinClosed| every model whose window was closed, whose buffer was deleted, or
whose anchor window switched content is torn down - including non-spinning
models that no tick would ever inspect. Use |wrfm.hide()| when a view should
survive such transitions instead.

Rendering pauses while the command-line window is open (opening floats under
it would raise), and a programmatic first render issued before the UI exists
(e.g. from init.lua) is queued until |VimEnter| so terminal dimensions are
known before derived canvas sizes clamp against them.

INLINE PREVIEW                                              *wrfm.inline*

The inline preview renders the wireframe as braille text inside the buffer
using virt_text overlay extmarks: the artwork is composited on top of the
buffer's real text cells.  The text scrolls with the buffer naturally and
is never pushed or rearranged (there is no virtual-lines push channel); no
graphics protocol or special terminal is needed.

Use `:WrfmHere` to toggle the preview, or configure auto-attach:

>lua
    require("wrfm").setup({
      integrations = {
        wrfm = {
          enabled = true,                     -- auto-attach for *.wrfm
          clear_in_insert_mode = false,       -- hide during insert mode
          only_render_at_cursor = false,      -- show only at cursor
          cursor_mode = "popup",              -- "popup" or "inline"
          filetypes = { "wrfm" },
        },
      },
    })
<

When `only_render_at_cursor` is true, the preview appears near the cursor
line only.  `cursor_mode = "popup"` shows a temporary floating window;
`"inline"` anchors the extmark to the cursor line.  In cursor-only mode the
preview follows the cursor: popup mode reopens at each new cursor position
and inline mode re-anchors the extmark, instead of closing on the first
movement.

An inline preview overlays the same cells the buffer paints, so it can
collide with text and other content. Two options govern that compositing
(see |wrfm.from_file()|):

- `overflow`: `"clip"` (default) crops the artwork to the canvas; `"visible"`
  bleeds it into the surrounding text, skipping cells with nowhere to land
  (left of the buffer, or past a line's end).
- `z_order`: `"model"` (default) paints over the colliding cell; `"text"`
  yields the cell to the buffer's content. Both are consumed on every
  inline render.

Because the overlay draws on real lines, the artwork is limited by the
buffer's own bounds and line widths (a cell past a line's end has nowhere to
stand). The canvas stays a crop box: `Model:overflows()` reports whether the
footprint exceeds it and `overflow = "visible"` bleeds outward.

When `clear_in_insert_mode` is true, all inline previews for the current
buffer are hidden during insert mode and restored on |InsertLeave|.

The old `from_file({ buffer = ... })` pattern that overwrote buffer content
is deprecated; use `wrfm.attach()` instead for a non-destructive preview.

HOT RELOAD                                                *wrfm.hot-reload*

With watch enabled (the default), viewers follow their source file and
repaint ~150ms after changes, preserving pitch/yaw/distance/spin state.

Inline previews also follow *unsaved* edits: an `on_lines` watcher on the
buffer re-parses the buffer content as you type, so the preview updates
without a `:write`. The two channels dedup against the last successfully
parsed text - writing the already-shown content back to disk does not
repaint.

- Directory-level fs_event watching survives editors replacing files via
  rename; filesystems lacking fs_event fall back to a 2s poll.
- Unparseable mid-edit states (typed or unsaved) keep the last good frame
  and warn once until the content becomes valid again.
- Deleting the file keeps the last frame and stops the watcher.
- Pass `watch = false` for a static snapshot (disables both channels).

HEALTH CHECK                                              *wrfm.checkhealth*

`:checkhealth wrfm` verifies the Neovim version floor, the render pipeline,
the parser, timer availability, prints the active configuration, and reports
whether the `wrfm` CLI is on PATH (only needed to regenerate test fixtures).

FAQ                                                            *wrfm.faq*

Why braille?           Plain text renders anywhere Neovim runs - ssh, tmux,
                       screen - without image protocol support.
vs. wireforge TUI?     Edit in the TUI; preview beside your editor here.
                       Hot reload bridges the two.  Project:
                       https://github.com/Vaishnav-Sabari-Girish/wireforge
Performance?           A typical frame rasterizes in well under a millisecond;
                       animation runs on a libuv timer at `fps`.
Over ssh/tmux?         Yes - braille characters are plain Unicode text. No
                       passthrough, no special configuration needed.
Terminal compatibility?Works with virtually all modern terminals: iTerm2,
                       Alacritty, Kitty, WezTerm, Ghostty, foot, Windows
                       Terminal, GNOME Terminal, Konsole, and more.
What .wrfm files?      Any valid .wrfm file. See the wireforge project for
                       format details and model generators:
                       https://github.com/Vaishnav-Sabari-Girish/wireforge

Development environment~

wrfm.nvim uses mise (https://mise.jdx.dev/) for task running and tool
version management. This replaces Makefile + Nix with a single tool.

Setting up the development environment:1. Install mise
>sh
    curl https://mise.run | sh
<2. Install pinned tool versions
>sh
    mise install
<   This installs the exact versions specified in .tool-versions:
   - act — local GitHub Actions runner   - stylua — Lua formatter3. Install test dependencies
>sh
    luarocks install busted
    luarocks install nlua
    luarocks install luassert
<4. Run the test suite
>sh
    mise run test
<5. Check formatting
>sh
    mise run format-check
<

Why mise instead of Makefile + Nix?~
- Single tool: handles both task running and tool version pinning
- No Nix dependency: works on any system without Nix
- Cross-platform: works on Linux, macOS, and Windows (WSL)
- Simpler: no Makefile boilerplate, no flake.nix complexity
- Reproducible: .tool-versions locks exact tool versions

The trade-off is that Nix provides more complete dependency isolation and
system library management. For wrfm.nvim's zero-dependency architecture,
mise is sufficient.

Running CI locally~

wrfm.nvim uses act (https://github.com/nektos/act) to run GitHub Actions
locally. This lets you test CI changes without pushing.
>sh
    mise run test-ci          # full CI
    mise run test-ci-stable   # stable Neovim only
    mise run test-ci-nightly  # nightly Neovim only
<The test-ci* tasks use /tmp/wrfm.nvim-act* for caching.
